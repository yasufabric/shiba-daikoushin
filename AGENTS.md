# しば大行進

Portrait phone game. Shibas march up the field, cat swarms come down, and a three-minute match ends at the cat castle. The only input is deploying a card. At 50 shibas the わんわん砲 clears the field.

Stack: Vite, TypeScript, Canvas 2D. No runtime dependencies. Art is original 8×8 pixel sprites. Sound is Web Audio synthesis.

## Commands

```bash
npm install
npm run dev
npm test
npm run build
npm run preview
```

`npm test` runs vitest against the match simulation. `npm run build` typechecks, then writes `dist/` with Vite `base` `/shiba-daikoushin/` for GitHub Pages.

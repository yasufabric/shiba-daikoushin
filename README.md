# しば大行進

Portrait defense. Drop shibas anywhere in your half, hold the 柴の家 against a pack of rival dogs, and beat the セントバーナード that comes out last.

https://yasufabric.github.io/shiba-daikoushin/

`?lanes` plays the older five-path version.

```bash
npm install
npm run dev
npm test
npm run build
```
